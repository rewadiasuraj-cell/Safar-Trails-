# Safar Trails SEO audit — 31 October 2026

Scope: all 58 URLs in the public sitemap were requested. 56 returned parseable HTML; About and Contact exhausted curl's redirect limit. Homepage and the Kashmir seasonal guide were also inspected after JavaScript rendering. This is a crawl/on-page audit, not a measured ranking or Core Web Vitals report.

## Findings and implemented fixes

| Priority | Evidence | Change |
| --- | --- | --- |
| Critical | `/about-us` returns 308 to `/about-us/`, which returns 301 to `/about-us`; Contact has the same failure. | Remove the conflicting slash-removal rules; add a regression guard for this Pages directory loop. |
| High | Destination requests redirect to trailing-slash directories, while canonical and sitemap URLs omit the slash. | Align page canonicals, sitemap, breadcrumb/entity URLs and prerendered links with directory URLs. Asset URLs are unchanged. |
| Medium | 5 titles and 28 descriptions in the 56 readable responses end in a literal ellipsis. The helper clipped copy before search engines received it. | Preserve complete source metadata; give the five affected guides concise titles and shorten the homepage description. Search engines can still choose different snippets or truncate display. |
| Medium | Footer destination and navigation entries are buttons, not anchors. | Render React Router Links with real hrefs, including the home logo. Keep modal actions as buttons. |
| Medium | Kashmir guide advertises month-by-month detail but contains four seasonal sections. | Rename the guide to match its seasonal coverage and write a concise summary. |
| Medium | Every sitemap lastmod is the deployment date, generated by `new Date()`. | Omit lastmod until reliable content modification dates are available. |

The trailing-slash change exposed an active-menu mismatch. Path-to-view resolution now normalizes both spellings; the regression suite covers it.

## Already working

- HTTPS responds; www redirects to the non-www hostname.
- Public robots.txt permits general search crawling and advertises the sitemap. Training-bot restrictions are not a Googlebot indexing block.
- Crawlable prerendered text, per-page metadata, H1s and internal links exist on the readable sitemap pages.
- TravelAgency, Article, TouristTrip, TouristDestination, breadcrumb and FAQ schema are present where applicable. Presence is not a guarantee of rich-result eligibility.
- A deliberately nonexistent root URL returned HTTP 404.
- The Kashmir guide displays its author and date after rendering; these must not be reported as absent based only on raw HTML.

## Remaining work

1. Deploy the reviewed branch, then verify About/Contact return 200 after at most one redirect and confirm canonical/sitemap URLs return 200 directly on Cloudflare. Local build checks do not replace edge verification.
2. Submit the updated sitemap in Search Console and inspect representative destination, package and guide URLs. No Search Console access or actual indexing/traffic data was available. An empty public site search does not establish deindexing.
3. Measure mobile Lighthouse and CrUX LCP/INP/CLS. No performance score was measured; the build has a roughly 565 kB uncompressed main chunk, which is a profiling lead, not proof of poor CWV.
4. Review Kashmir travel-access/safety claims and seasonal opening dates against current official sources. Confirm the genuine author identities and replace stock portraits where they could misrepresent a named person. No claim is made that the named author is fictitious.
5. Verify Google Business Profile phone/address, real review links and precise map coordinates with the business owner. No GBP or backlink audit was performed.
6. Review remaining longer metadata editorially; preserving complete sentences fixes source clipping but does not guarantee that all descriptions fit a search snippet.

## Validation

- `npm test`: 6 tests pass, including the live redirect-loop fixture and slash-normalized menu state.
- `npm run lint`: TypeScript passes.
- `npm run build:pages`: 59 static pages, 58 sitemap URLs; historical URL guard passes (one retired URL covered by redirect).
- Browser rendering was checked on production. The local preview could not be reached by the connected browser, so no local visual approval or CWV claim is made.
- No full SEO health score is assigned because performance, indexing and authority data were unavailable.
